# Claude Code skills for this test suite

This folder holds two [Claude Code skills](https://docs.claude.com/en/docs/claude-code/skills) for testing the Cartwheel storefront. `manual-test-cases` turns a feature brief, user story or description into a small, risk-based set of manual test cases. It models the feature, derives cases from its rules and risks, prioritises them by business impact, cuts both gaps and bloat, and gives every case a stable ID ready for automation. `automation-code-review` reviews Playwright + TypeScript test code for locator strategy, web-first assertions, fixed waits, test isolation, page-object design, flake risk, naming and traceability to those case IDs, and ends with a pass/fail verdict. Claude Code loads them automatically from `.claude/skills/` when you open this project. Ask in plain language, for example "write test cases for guest checkout" or "review the Playwright changes on this branch", or invoke one directly with `/manual-test-cases` or `/automation-code-review`. For a first draft in a few minutes, ask for quick mode: `/manual-test-cases quick docs/specs/<feature>.md` reads only the spec and writes at most 8 cases. Each `SKILL.md` links to its `references/` files, and Claude reads those as it needs them.
